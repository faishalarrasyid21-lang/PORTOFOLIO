# Portofolio Pribadi | Faishal Arrasyid 

Selamat datang di repositori portofolio pribadi saya! Proyek ini adalah situs web portofolio interaktif dan modern yang dibangun untuk memamerkan keahlian saya sebagai seorang **Frontend Web Developer**, serta menampilkan hobi dan proyek-proyek terbaru saya.

Situs web ini dirancang dengan estetika bertema kosmik (luar angkasa) gelap dengan animasi tingkat lanjut untuk memberikan pengalaman antarmuka pengguna (UI) yang memukau dan "hidup".

## ✨ Fitur Utama

- **Desain Tema Kosmik & Kaca Transparan (*Glassmorphism*)**: Antarmuka modern dengan warna gelap elegan, disempurnakan dengan efek kaca yang menyatu dengan latar belakang luar angkasa.
- **Animasi WebGL & Three.js Interaktif**: Menampilkan efek kilatan petir (*lightning*) kosmik di latar belakang yang bisa diubah warnanya secara *real-time* oleh pengguna melalui *slider*.
- **Animasi Lanjutan dengan GSAP & Framer Motion**: Transisi halaman yang sangat mulus, efek *scroll parallax*, elemen yang melayang, dan animasi *reveal* saat pengguna menggulir halaman.
- **Kursor Khusus (*Custom Magnetic Cursor*)**: Kursor membulat kustom yang secara dinamis dan magnetik berinteraksi dengan tombol-tombol atau elemen yang dapat diklik di seluruh halaman.
- **Responsif Sepenuhnya**: Layout yang telah dioptimalkan agar terlihat sempurna di berbagai perangkat mulai dari layar *desktop* besar hingga perangkat *mobile*.

## 🛠️ Teknologi yang Digunakan

Proyek ini dibangun di atas ekosistem pengembangan web modern, menggabungkan alat dan perpustakaan terbaik di kelasnya:

- **Inti (*Core*)**: [React.js](https://reactjs.org/) & [Vite](https://vitejs.dev/)
- **Desain & Gaya (*Styling*)**:
  - [Tailwind CSS](https://tailwindcss.com/) (Untuk utilitas cepat & *layout*)
  - [Styled Components](https://styled-components.com/) (Untuk kustomisasi CSS terisolasi)
- **Animasi & Interaktivitas**:
  - [Framer Motion](https://www.framer.com/motion/) (Animasi tata letak & transisi)
  - [GSAP (GreenSock)](https://greensock.com/gsap/) (Animasi *scroll* kompleks)
  - [Three.js](https://threejs.org/) (Untuk latar belakang kanvas WebGL 3D)
- **Hosting & Deployment**: [Firebase Hosting](https://firebase.google.com/docs/hosting)

## 📁 Struktur Bagian Utama

- **Hero / Beranda**: Menampilkan nama saya, perkenalan singkat, dan *slider* pengontrol warna petir kosmik.
- **Tentang Saya**: Penjelasan mendalam mengenai latar belakang, minat, dan ambisi saya di dunia pengembangan web.
- **Karya (Portofolio)**: Galeri atau daftar proyek-proyek unggulan yang pernah saya kerjakan.
- **Hobi & Minat**: Sorotan mengenai hal-hal yang saya senangi di luar pengkodean (seperti Teknologi, *Visual Art*, dan Desain Grafis).

## 🚀 Cara Menjalankan Secara Lokal

Jika Anda ingin mencoba menjalankan atau bereksperimen dengan proyek ini di komputer Anda sendiri, ikuti langkah-langkah berikut:

1. **Kloning Repositori ini:**
   ```bash
   git clone git@github.com:faishalarrasyid21-lang/PORTOFOLIO.git
   cd PORTOFOLIO
   ```

2. **Instal Dependensi:**
   Pastikan Anda sudah menginstal Node.js, lalu jalankan:
   ```bash
   npm install
   ```

3. **Jalankan Server Pengembangan (Dev Server):**
   ```bash
   npm run dev
   ```
   Situs akan berjalan secara lokal.

4. **Kompilasi (Build) untuk Produksi:**
   ```bash
   npm run build
   ```
